Not sure which Mac you have? Click the Apple menu  → **About This Mac**. It says *Chip: Apple…* or *Processor: Intel…*.

## Opening Lucid for the first time

Lucid is a prototype, so it isn't registered with Microsoft or Apple yet. Your computer asks once
before opening it:

- **Windows:** unzip, then double-click **Lucid.exe**. If you see *"Windows protected your PC"*,
  click **More info → Run anyway**.
- **Mac:** double-click the zip, drag **Lucid** to Applications, then **right-click** it and choose
  **Open → Open**. After that it opens normally.
- **Linux:** unpack, then double-click **Lucid** (or right-click → **Run as a Program**).
